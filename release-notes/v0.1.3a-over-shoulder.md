## Fixes

- **No more flash of the fixed camera at some doors.** Doors that lead to
  another part of the house load it in the background, and for those few
  frames the over-the-shoulder camera used to hand control back, so the
  room's fixed angle flashed. It now stays over the shoulder. Doors between
  rooms in the same part of the house were never affected.

## From MikuPan

- **PS2 save import** now creates numbered PC saves (or replaces the one you
  select) instead of the old three slots. A memory card with saves from
  several regions asks which to import, Korean and Asian saves convert too,
  and imported saves get a preview picture from the game's own save artwork.
- **EU save screens** read their pictures from the right place; battle mode
  saves could crash the EU version.
- **PS2 memory card listing** no longer loses saves to preview files.

## Installing

1. Download the zip for your platform and your game's region: **US** for the
   NTSC-U (USA) disc, **EU** for the PAL (EU) disc. NTSC-J discs are not
   supported.
2. Extract it, then copy `IMG_HD.BIN` and `IMG_BD.BIN` from your disc next to
   the `MikuPan` executable.
3. In game, open **Settings › Game › Camera** and set **Camera View** to
   **Over the Shoulder**.

These packages are Debug builds, as the README recommends: the Release
configuration has known issues.
